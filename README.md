# JXYCOI Display Better（育才信奥界面美化脚本）

简介：

一个用于美化育才信奥 OJ 界面的篡改猴用户脚本。

核心能力：

🎨 自制主题：面板中实时调整主题色、背景色、背景图、图片设置、圆角等，形成自己的主题

📥 导入洛谷主题：以洛谷官方主题 JSON 格式（lNavi / lBody / dNavi / dBody）导入，可额外携带 name / author / css 等元素，不能少字段

🥚 彩蛋主题：导入框输入「艾莲·乔」「艾莲」「艾莲乔」「默认」时应用专属主题（白色文字描边）

📤 导出主题：把当前配置导出为洛谷格式 JSON，可分享给他人

🌫️ 背景模糊度调节：0–40px 滑块，配合背景图可实现毛玻璃效果

🔍 卡片透明度调节：0%–100% 滑块（0=完全透明，1=不透明）

🖼️ 图片设置：位置 X / 位置 Y、尺寸（自动/填充/适应/自定义）、重复（不重复/全部/横向/纵向）、亮度、旋转，以洛谷 midOpts 为标准

🏷️ 去除首页图片：可一键隐藏首页轮播/公告大图（/api/public/img/xxx.png）

🃏 卡片化：导航栏、班级内导航/课程/训练/排名、训练/排名/题单、团队内部等几乎所有区域卡片化；点进题目或比赛开始做题时自动豁免（纯白）

🌓 预设主题：洛谷经典蓝 / 洛谷翠绿 / 洛谷暮紫 / 洛谷暗夜 / 毛玻璃亚克力

💾 配置持久化：GM 存储（自动回退 localStorage），刷新页面后保持
